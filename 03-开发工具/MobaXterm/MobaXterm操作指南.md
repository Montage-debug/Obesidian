# 二、启用流程
## 1、在目标计算机上启用 SSH 服务

```c
您需要确保目标计算机已安装并启用 **OpenSSH 服务器**。

1. 打开目标计算机的 **设置** → **应用** → **可选功能**。
    
2. 点击 **添加功能**，搜索并安装 **OpenSSH Server**。
    
3. 安装后，打开 **PowerShell**（以管理员身份），运行以下命令启动 SSH 服务：
    
    `Start-Service sshd`
    
4. 为了确保 SSH 服务在启动时自动运行，您可以运行以下命令：
    
    `Set-Service -Name sshd -StartupType 'Automatic'`

```
## 2、在目标计算机上确认防火墙设置


```c
确保 Windows 防火墙允许端口 22（SSH）的访问。可以在 **控制面板** → **Windows 防火墙** → **允许应用通过防火墙通信** 中进行设置。
```

## 3、通过 MobaXterm 连接

```c
- 打开 MobaXterm，点击左上角的 **Session**。
    
- 在弹出的窗口中，选择 **SSH** 作为连接类型。
    
- 输入目标计算机的 **IP 地址** 和 **登录用户名**，点击 **OK**。
    
- 如果一切设置正确，MobaXterm 会提示您输入密码，然后就可以通过 SSH 连接到目标计算机了。
```

# 三、另一种方法

```
### 方法 2: 使用 **RDP**（远程桌面协议）连接

1. **启用远程桌面**  
    在目标计算机上启用远程桌面功能：
    
    1. 打开目标计算机的 **设置** → **系统** → **远程桌面**。
        
    2. 启用 **远程桌面** 选项。
        
    3. 确保您选择了 **允许从任何版本的远程桌面连接**（对于 Windows 10 或更高版本）。
        
2. **配置防火墙**  
    确保目标计算机的防火墙允许远程桌面连接。可以通过 **控制面板** → **Windows 防火墙** 中进行设置，允许端口 3389（RDP）。
    
3. **在 MobaXterm 中连接**
    
    1. 打开 MobaXterm，点击左上角的 **Session**。
        
    2. 选择 **RDP** 作为连接类型。
        
    3. 输入目标计算机的 **IP 地址** 和 **用户名**，然后点击 **OK**。
        
    4. 输入密码后，就可以通过 RDP 连接到目标计算机了。
```
