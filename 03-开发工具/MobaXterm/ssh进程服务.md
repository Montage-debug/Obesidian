```shell
# 安装ssh服务
sudo apt install openssh-server
```

```
# 查看服务状态
sudo systemctl status ssh
```

```
脚本开机自启动
sudo systemctl enable [服务名]   
```


| 命令                                 | 立即生效？          | 主要作用                       | 类比解释                      |
| ---------------------------------- | -------------- | -------------------------- | ------------------------- |
| **`sudo systemctl start [服务名]`**   | **是**          | **立即启动**一次该服务。             | **“请现在打开这个程序。”**          |
| **`sudo systemctl enable [服务名]`**  | **否** (影响下次启动) | 配置服务为**开机自动启动**。           | **“请记住，以后每次开机都要自动打开它。”**  |
| **`sudo systemctl stop [服务名]`**    | **是**          | **立即停止**正在运行的服务。           | **“请现在关闭这个程序。”**          |
| **`sudo systemctl disable [服务名]`** | **否** (影响下次启动) | 取消服务的**开机自动启动**。           | **“以后开机不用再自动打开它了。”**      |
| **`sudo systemctl restart [服务名]`** | **是**          | **立即重启**服务（先停后启）。          | **“请现在关闭并重新打开这个程序。”**     |
| **`systemctl status [服务名]`**       | -              | **查看**服务的**当前状态**和是否已启用自启。 | **“这程序现在开着吗？它设置了开机自启吗？”** |
