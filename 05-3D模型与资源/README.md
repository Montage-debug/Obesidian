## 🔧 使用说明

### 打开和编辑CAD文件

#### 推荐软件

**免费软件：**
- **FreeCAD** - 开源3D CAD建模软件
  - 支持格式：STEP, IGES, STL等
  - 平台：Windows, Linux, macOS
  - 下载：[https://www.freecad.org/](https://www.freecad.org/)

- **Fusion 360** - Autodesk免费版（个人/教育）
  - 功能强大的参数化建模
  - 支持云协作
  - 下载：[https://www.autodesk.com/products/fusion-360](https://www.autodesk.com/products/fusion-360)

**专业软件：**
- SolidWorks
- CATIA
- AutoCAD
- Inventor

#### 文件导入流程
1. 打开CAD软件
2. 选择 `文件` -> `导入` 或 `打开`
3. 选择 `.stp` 或 `.step` 文件
4. 调整导入选项（单位、坐标系等）
5. 确认导入

## 📚 相关资源

### CAD文件格式说明

#### STEP (.stp/.step)
- **全称**：Standard for the Exchange of Product model data
- **特点**：国际标准、通用性强、保留参数信息
- **用途**：CAD软件间数据交换

#### IGES (.igs/.iges)
- **全称**：Initial Graphics Exchange Specification
- **特点**：较早的交换标准
- **用途**：CAD数据交换（逐渐被STEP取代）

#### STL (.stl)
- **全称**：STereoLithography
- **特点**：三角面片表示、文件较大
- **用途**：3D打印、可视化
