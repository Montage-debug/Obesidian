**`libserial-dev`** 和 **`libserial1`**：

- **`libserial-dev`**：这是一个 C++ 开发包，用于串口编程。它包含了开发所需的头文件和库文件。
    
- **`libserial1`**：这是 `libserial` 的运行时版本，包含了串口通信的实现。
    

这两个包应该配套使用，`libserial-dev` 提供开发时的头文件和静态库，而 `libserial1` 提供运行时需要的动态库。因此，它们并不是重复的，而是同一功能的不同部分。

当Anaconda 环境中使用的 `libstdc++.so.6` 版本太低，缺少 `GLIBCXX_3.4.30`，而 ROS 2 的 `librclcpp.so` 库需要这个版本的时候
### 使用 `LD_PRELOAD` 强制使用系统的 `libstdc++`

你可以通过强制加载系统版本的 `libstdc++` 来绕过 Anaconda 环境中存在的库冲突：

`export LD_PRELOAD=/usr/lib/x86_64-linux-gnu/libstdc++.so.6 ros2 run serial_communication_cpp serial_node`
