Elite常用指令
```c
# 移动到 home 点
ros2 service call /arm/set_joint_pose robot_interfaces/srv/ArmSetJointPose "{pose_name: 'home'}"

# 移动到指定点
ros2 service call /arm/move_to_point robot_interfaces/srv/ArmMoveToPoint \
"{target_point: {
  waypoint: [0.37666, 0.14090, 0.60345, 2.9400, -0.4403, 0.5031],
  velocity: 0.3,
  acceleration: 0,
  use_tcp_offset: false
}}"
# 注：请求用工具位置笛卡尔空间姿态信息
# 注：预设位置用关节位置角度信息，如预设Home点
```


```c
# 系统进入保护性停止，解除
ros2 service call /arm/unlock_protective_stop std_srvs/srv/Trigger

# 取消运动
ros2 service call /arm/cancel_motion std_srvs/srv/Trigger

# 重启机器人控制器
ros2 service call /arm/reset_arm std_srvs/srv/Trigger
```


```c
# tcp使用预设
ros2 service call /arm/set_tcp robot_interfaces/srv/ArmSetTCP "{

use_preset: true

}"

# tcp设置
ros2 service call /arm/set_tcp robot_interfaces/srv/ArmSetTCP "{

use_preset: false,

tcp_offset: [0.0, 0.0, 0.05, 0.0, 0.0, 0.0]

}"
```
