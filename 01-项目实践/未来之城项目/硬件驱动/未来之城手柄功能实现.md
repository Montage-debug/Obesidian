| 7     | 0x00  | 固定字段（预留，暂未使用）                     |

|步骤|操作|文件位置|
|---|---|---|
|1️⃣|创建文件 `protocol_v2.hpp` / `protocol_v2.cpp`|`include/massage_head_manager/` 与 `src/`|
|2️⃣|在 `protocol_v2.hpp` 中定义 `class ProtocolV2 : public IProtocol`|同 V1 结构|
|3️⃣|实现 `parsePacket()`、`printParseResult()`、`buildCommand()`|`protocol_v2.cpp`|
|4️⃣|在 `massage_head_base.cpp` 中注册|例如：`protocols_.push_back(std::make_shared<ProtocolV2>(node_->get_logger()));`|
|5️⃣|在 launch 文件中选择使用哪种协议|例如通过参数 `"protocol_version:=v2"` 控制加载|

**总体原则**：让每个 `.cpp` 只包含它需要的头（减少头文件膨胀，缩短编译时间）。把公共类型声明放 `include/massage_head_manager/*.hpp`。

|文件|作用|与谁交互|
|---|---|---|
|**massage_head_manager.cpp**|ROS2 节点主逻辑，负责接收串口消息、调用解析器、发布状态、周期性查询手柄|订阅 `serial_data`、发布 `massage_head_manager` 与 `massage_head_status`|
|**protocol_parser.cpp**|负责识别协议帧、解析命令、调用当前手柄对象处理|被 `massage_head_manager.cpp` 调用|
|**massage_head_base.cpp**|各类型手柄对象实现（识别、温度、电机、LED 等）|被 `protocol_parser.cpp` 调用|
|**serial_utility.cpp**|处理字符串与字节数据转换、校验|被 `massage_head_manager.cpp` 与 `protocol_parser.cpp` 调用|
|**MassageHeadStatus.msg**|ROS 消息定义，表示一个手柄的完整状态|被所有节点引用与发布|


|流向|内容|作用|
|---|---|---|
|STM32 → serial_data|原始数据帧（例如识别命令响应）|底层数据输入|
|serial_data → protocol_parser|HEX 转字节后解析命令|协议解释|
|protocol_parser → MassageHeadStatus.msg|生成 ROS 状态消息|抽象成统一格式|
|massage_head_manager → massage_head_status|发布状态|上层可订阅查看状态|
|massage_head_manager → massage_head_manager|下发命令（字符串）|串口节点负责写回 STM32|

```shell

# 示例
  # USB串口设备固定规则
# 根据USB端口位置分配固定的串口号,不受设备类型影响
# 
# 使用方法:
# 1. 插入USB设备后,运行: udevadm info -a -n /dev/ttyUSB0 | grep -E '(idVendor|idProduct|serial|KERNEL)'
# 2. 根据输出信息填写对应规则
# 3. 重新加载规则: sudo udevadm control --reload-rules && sudo udevadm trigger

# 端口1 - 根据物理USB端口位置
SUBSYSTEM=="tty", KERNELS=="1-11",SYMLINK+="tty_massage_head_manager", MODE="0666", GROUP="dialout"

# 端口2
SUBSYSTEM=="tty", KERNELS=="1-10",SYMLINK+="tty_system_manager", MODE="0666", GROUP="dialout"

```

```shell
# 可将其作为.sh 脚本文件运行
#!/bin/bash

udev规则安装脚本


set -e

SCRIPT_DIR="$( cd "$( dirname "${BASH_SOURCE[0]}" )" && pwd )"
UDEV_RULE_FILE="99-usb-serial-bymyself.rules"
UDEV_RULE_PATH="/etc/udev/rules.d/${UDEV_RULE_FILE}"

echo "================================================"
echo "udev规则安装"
echo "================================================"
echo ""

# 检查udev规则文件是否存在
if [ ! -f "${SCRIPT_DIR}/${UDEV_RULE_FILE}" ]; then
    echo "错误: 找不到udev规则文件 ${UDEV_RULE_FILE}"
    exit 1
fi

echo "1. 复制udev规则文件到系统目录..."
sudo cp "${SCRIPT_DIR}/${UDEV_RULE_FILE}" "${UDEV_RULE_PATH}"
echo "   ✓ 已复制到 ${UDEV_RULE_PATH}"

echo ""
echo "2. 重新加载udev规则..."
sudo udevadm control --reload-rules
echo "   ✓ udev规则已重新加载"

echo ""
echo "3. 触发udev规则..."
sudo udevadm trigger
echo "   ✓ udev规则已触发"

echo ""
echo "4. 将当前用户添加到dialout组..."
sudo usermod -a -G dialout "$USER"
echo "   ✓ 用户 $USER 已添加到dialout组"
echo "   ⚠ 注意: 需要注销并重新登录才能生效"

echo ""
echo "================================================"
echo "安装完成!"
echo "================================================"
echo ""
echo "验证步骤:"
echo "1. 拔掉并重新插入设备"
echo "2. 运行以下命令检查设备:"
echo "   ls -l /dev/tty_system_manager"
echo "   ls -l /dev/tty_massage_head_manager"
echo "   udevadm info -a -n /dev/tty_system_manager"
echo "   udevadm info -a -n /dev/tty_massage_head_manager"
echo ""
echo "3. 如果设备没有出现,请检查:"
echo "   - 设备是否已连接"
echo "   - 运行: udevadm info -a -n /dev/ttyUSB0 | grep serial"
echo ""

```
