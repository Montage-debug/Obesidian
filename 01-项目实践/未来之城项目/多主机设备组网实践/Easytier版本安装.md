1、适配ubuntu22.04版本安装
```c
wget https://github.com/EasyTier/EasyTier/releases/download/v2.5.0/easytier-gui_2.5.0_amd64.deb

# 1. 下载
wget -P ~/Downloads https://github.com/EasyTier/EasyTier/releases/download/v2.5.0/easytier-gui_2.5.0_amd64.deb

# 2. 安装
sudo apt install ~/Downloads/easytier-gui_2.5.0_amd64.deb

# 3. 启动
easytier-gui &

```
