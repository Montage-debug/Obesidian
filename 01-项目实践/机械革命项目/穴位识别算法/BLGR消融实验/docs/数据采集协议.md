# 数据采集协议

> 版本：2026-07-06  
> 适用：BLGR 消融实验四组（Exp1-4）的数据采集与 GT 标注规范

---

## 一、测试数据集构成

| 分组 | 数量 | 用途 |
|------|------|------|
| 不同体型（Thin/Medium/Large，各 ≥10 人） | ≥ 30 帧 | Exp1 / Exp2 |
| 不同距离（1.0/1.5/2.0 m，同一批受试者 3~5 人） | ≥ 45 帧 | Exp3 |
| 新增穴位验证（任意体型） | ≥ 10 帧 | Exp4 |

---

## 二、拍摄规范

### 2.1 通用要求

- 受试者俯卧位，面部朝下，背部朝上，双臂自然放于体侧
- 背部裸露，颈椎到尾骨全部可见
- 相机正对背部（上下偏差 < 5°），垂直于床面
- 光线均匀，避免强烈阴影遮挡背部

### 2.2 三距离拍摄（Exp3 专用）

| 距离 | 地面标记颜色 | 备注 |
|------|------------|------|
| 1.0 m | 红色胶带 | 相机镜头中心到受试者颈椎投影点 |
| 1.5 m | 黄色胶带 | 标准测量距离（生产环境） |
| 2.0 m | 绿色胶带 | 远距离场景 |

每个距离段对同一受试者拍摄 3 帧，计算时取均值。

## 三、文件格式规范

### 3.1 主 GT 文件：`data/gt.csv`

用于 Exp1 / Exp2 / Exp3，包含 9 个测试穴位的标注。

**列定义**：

| 列名 | 类型 | 说明 |
|------|------|------|
| `image_id` | string | 图像唯一标识，如 `img_001` |
| `acupointCode` | string | 穴位编码，如 `GV14`、`BL13_R` |
| `x_px` | float | 中医师标注的穴位 x 像素坐标 |
| `y_px` | float | 穴位 y 像素坐标 |
| `x_cm` | float | 物理 x 坐标（cm），由 px_to_cm 换算 |
| `y_cm` | float | 物理 y 坐标（cm） |

**示例行**（合成数据，非实测）：

```
image_id,acupointCode,x_px,y_px,x_cm,y_cm
img_001,GV14,320.5,142.3,18.2,8.1
img_001,BL13_R,345.2,142.3,19.6,8.1
img_002,GV14,318.0,140.0,18.1,7.9
```

### 3.2 新穴位 GT 文件：`data/gt_ext.csv`

仅用于 Exp4，格式与 `gt.csv` 完全相同，但仅包含 5 个新穴位：
`GV15 / GV16 / BL10_R / EX-B1_R / EX-B4_R`

### 3.3 受试者元数据：`data/subjects.csv`

用于 Exp2 体型分组。

| 列名 | 类型 | 说明 |
|------|------|------|
| `image_id` | string | 与 gt.csv 中的 image_id 对应 |
| `subject_id` | string | 受试者编号，如 `S001` |
| `body_type` | string | `Thin` / `Medium` / `Large` |
| `bmi` | float | 受试者 BMI，如 `22.5` |

**示例行**（合成数据）：

```
image_id,subject_id,body_type,bmi
img_001,S001,Medium,23.1
img_002,S002,Thin,17.8
img_003,S003,Large,27.4
```

**体型划分标准**：

| 分组 | BMI 范围 | 参考外观特征 |
|------|---------|------------|
| Thin | < 18.5 | 肋骨隐约可见，肩宽与胯宽比偏大 |
| Medium | 18.5~24.9 | 标准体型，肩宽胯宽比例协调 |
| Large | ≥ 25 | 腰胯部较宽，脂肪层明显 |

### 3.4 拍摄距离元数据：`data/distance_meta.csv`

用于 Exp3 距离分组。

| 列名 | 类型 | 说明 |
|------|------|------|
| `image_id` | string | 与 gt.csv 对应 |
| `distance_m` | float | 拍摄距离（m），值为 `1.0` / `1.5` / `2.0` |

**示例行**（合成数据）：

```
image_id,distance_m
img_d_001,1.0
img_d_002,1.5
img_d_003,2.0
```

### 3.5 关键点 JSON：`data/keypoints.json`

YOLO 推理后序列化的关键点文件。

```json
{
  "img_001": {
    "left_shoulder":  [110.0, 201.0, 0.92],
    "right_shoulder": [290.0, 201.0, 0.94],
    "left_hip":       [136.0, 473.0, 0.88],
    "right_hip":      [264.0, 473.0, 0.91],
    "neck":           [200.0, 156.0, 0.85]
  }
}
```

坐标格式：`[x_pixel, y_pixel, confidence]`，confidence 范围 0~1。

## 四、像素到 cm 换算方法

**推荐方法**（无深度图时）：利用颈椎到髋中点的已知体长换算

```python
# 成年人背长（颈椎到髋中点）约 50 cm，可根据受试者实测修正
cm_per_pixel = 50.0 / neck_to_hip_pixels
```

**精确方法**（有深度图时）：通过相机内参直接反投影

```
x_cm = (u - cx) * Z / fx / 10   # mm → cm
y_cm = (v - cy) * Z / fy / 10
```

## 五、GT 标注操作步骤

1. 用 LabelImg 或 OpenCV 自定义工具打开采集的图像
2. 对每张图像，逐一定位测试穴位集中的穴位，记录像素坐标
3. 通过换算得到物理坐标 (x_cm, y_cm)，填入对应 CSV

**标注质量控制**：
- 建议两位标注者独立标注后取平均值
- 两者差异 > 5 px（≈ 0.3 cm）时，需重新确认
- 标注后对结果可视化复核（将坐标叠加到原图验证位置合理性）
