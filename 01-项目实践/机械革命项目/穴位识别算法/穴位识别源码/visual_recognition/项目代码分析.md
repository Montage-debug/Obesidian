# visual_recognition 项目代码分析

## 项目概览

这是一个 **ROS 2 视觉穴位识别节点**（`visual_recognition`），用于**机械革命按摩机器人**项目。它接收人体照片，通过深度学习姿态估计模型定位人体关键点，再结合穴位配置数据推算出穴位坐标，返回给上层控制系统。

## 各文件详细说明

### 构建与配置

#### `setup.py`
ROS 2 ament_python 包的安装脚本。核心功能：
- 注册 `visual_recognize` 命令行入口点（`console_scripts`）
- 收集 `acu_config`、`models`、`third_tool` 子目录中的资源文件打入包内
- 排除 `test` 和 `visual_recognition_original`（PyArmor 混淆备份）目录
- 声明依赖 `setuptools`，测试依赖 `pytest`

#### `setup.cfg`
指定脚本安装路径到 `lib/visual_recognition`。

#### `package.xml`
ROS 2 包清单（format 3），声明：
- **运行时依赖**: `std_msgs`、`std_srvs`、`robot_interfaces`、`license_manager`
- **测试依赖**: `ament_copyright`、`ament_flake8`、`ament_pep257`、`python3-pytest`
- **构建类型**: `ament_python`

### 核心代码

#### `visual_recognition/__init__.py`
包初始化文件，仅声明版本号 `0.0.0`。

#### `visual_recognition/visual_recognize.py`
**ROS 2 节点主入口**，实现 `VisualRecognizeNode` 类：

- **服务**: 创建 `/visual/recognize_acupoint` 服务（类型 `VisualAcupointRecognize`）
- **心跳**: 每秒发布一次 `ModuleStates` 消息到 `/visual_recognize/states`，供系统监控进程存活
- **核心回调 `recognize_acupoint_callback`**:
  1. 接收 base64 编码的图片 + `body_part_code`（部位代码）
  2. base64 解码 → numpy 数组 → OpenCV 图像
  3. 调用 `draw_point.py` 中的 `chose_body_part()` 执行识别
  4. 将返回的穴位坐标列表封装为 `AcupointInfo` 消息
  5. 返回 `return_code`、`return_msg`、`acupoints_data_list`、`shoulder_width`、`hip_width`
- **`main()` 函数**: 先执行 `license_validator_py.check_system_license()` 授权验证，通过后才初始化 rclpy 并 spin 节点

#### `visual_recognition/draw_point.py`
**核心算法文件**（约 1300+ 行），包含全部视觉识别逻辑：

**模型管理**:
- 所有模型文件使用 **Fernet 对称加密**（AES-128-CBC），密钥硬编码在文件中
- 运行时解密到临时目录（`DECRYPTED_RKNN_DIR_CACHE` / `DECRYPTED_OPENVINO_DIR_CACHE`），避免重复解密
- YOLO 模型实例缓存（`YOLO_MODEL_CACHE`），避免重复初始化
- 模块加载时自动预加载所有模型（x86 平台）

**推理引擎适配**:
- **x86 平台**: 使用 OpenVINO 推理引擎（Intel CPU/GPU 加速），配置缓存目录 `openvino_cache`
- **ARM 平台**: 使用 RKNN 推理引擎（瑞芯微 NPU 加速），通过 `ctypes` 预加载 `librknnrt.so` 和 `librknn_api.so`

**部位识别路由** (`chose_body_part`):
| body_part_code | 部位 | 穴位配置文件 | 处理函数 |
|---|---|---|---|
| `BP004` | 背部 | `acupoints_config.enc` | `draw_back_acupoints_on_original()` |
| `BP014` | 腹部 | `abdomen_acupoints_config.enc` | `draw_abdomen_acupoints_on_original()` |
| `BP010` | 腿部 | `leg_acupoints_config.enc` | `draw_leg_acupoints_on_original()` |

**关键点检测**:
- 使用 YOLO 姿态估计模型检测人体关键点（肩、髋、膝、踝、肚脐、腕、颈等）
- 定义了各部位的默认关键点坐标（`DEFAULT_BACK_KEYPOINTS`、`DEFAULT_ABDOMEN_KEYPOINTS`、`DEFAULT_LEG_KEYPOINTS`），作为检测失败时的 fallback

**穴位推算**:
- 从加密 JSON 配置中读取每个穴位相对于人体关键点的偏移规则
- 根据检测到的关键点坐标 + 偏移比例计算出各穴位的像素坐标
- 计算并返回肩宽（`shoulder_width`）和髋宽（`hip_width`）

**可视化**:
- 通过环境变量 `YOLO_ENABLE_VIS` 控制是否保存标注图
- 在图像上绘制关键点和穴位点，保存为 `body_with_landmark.jpg`

**清理**:
- 每次识别完成后自动删除 YOLO 生成的 `runs/` 目录

### 模型文件 (`models/`)

| 模型 | OpenVINO 版大小 | RKNN 版大小 | 用途 |
|---|---|---|---|
| `neck_x` | ~139 MB | ~139 MB | 颈部/肩部关键点检测 |
| `x-pose` | ~139 MB | ~139 MB | 全身姿态估计（X-Pose） |
| `n-abdomen_navel_only` | ~6.3 MB | ~6.5 MB | 腹部 + 肚脐关键点检测 |

- 所有模型均使用 Fernet 加密存储（`.enc` 后缀）
- `openvino_models/` 目录存放解密后的 OpenVINO IR 格式文件（`.xml` + `.bin`）
- `openvino_cache/` 存放 OpenVINO 编译缓存（加速后续加载）

---

### 穴位配置文件 (`acu_config/`)

| 文件 | 大小 | 内容 |
|---|---|---|
| `acupoints_config.enc` | 35 KB | 背部穴位配置，定义各穴位相对于关键点的偏移规则 |
| `abdomen_acupoints_config.enc` | 11 KB | 腹部穴位配置 |
| `leg_acupoints_config.enc` | 4 KB | 腿部穴位配置 |

- 均为 Fernet 加密的 JSON 文件
- 通过 `load_encrypted_json()` 函数解密加载
- 内容结构：穴位名称 → 参考关键点 → 偏移比例/距离

---

### 第三方库 (`third_tool/`)

| 文件 | 用途 |
|---|---|
| `librknnrt.so` | 瑞芯微 RKNN 运行时库（ARM 板端 NPU 推理） |
| `librknn_api.so` | RKNN API 动态库 |

- 仅在 ARM 架构（`aarch64`）上加载
- 通过 `LD_LIBRARY_PATH` 和 `ctypes.CDLL` 预加载，确保优先使用项目内置版本

## 核心工作流程

```
ROS 2 服务请求 (base64图片 + 部位代码)
        │
        ▼
  visual_recognize.py  — VisualRecognizeNode
  ├─ base64 解码 → OpenCV 图像 (cv2.imdecode)
  ├─ 调用 chose_body_part(image, body_part_code)
        │
        ▼
  draw_point.py  — 核心算法
  ├─ 根据 body_part_code 路由:
  │   ├─ BP004 (背部) → draw_back_acupoints_on_original()
  │   ├─ BP014 (腹部) → draw_abdomen_acupoints_on_original()
  │   └─ BP010 (腿部) → draw_leg_acupoints_on_original()
  │
  ├─ 解密并加载对应的 YOLO 姿态估计模型
  │   ├─ x86: OpenVINO 推理引擎 (Intel CPU/GPU)
  │   └─ ARM: RKNN 推理引擎 (瑞芯微 NPU)
  │
  ├─ 模型推理 → 获取人体关键点坐标
  │   (肩、髋、膝、踝、肚脐、腕、颈等)
  │
  ├─ 加载加密穴位配置文件
  │   └─ 根据关键点坐标 + 偏移规则 → 计算穴位像素坐标
  │
  ├─ 计算肩宽、髋宽
  │
  └─ 返回: (success, status_code, message, acupoints, shoulder_width, hip_width, annotated_image)
        │
        ▼
  visual_recognize.py
  ├─ 封装为 AcupointInfo[] 列表
  └─ 返回 ROS 2 Response
```

## 技术栈总结

| 层级 | 技术 |
|---|---|
| **框架** | ROS 2 Humble (rclpy) |
| **姿态估计** | YOLO + X-Pose（Ultralytics） |
| **推理引擎** | OpenVINO（x86 Intel CPU/GPU）、RKNN（ARM 瑞芯微 NPU） |
| **图像处理** | OpenCV (cv2) |
| **模型加密** | Fernet 对称加密（AES-128-CBC，cryptography 库） |
| **代码保护** | PyArmor 混淆 |
| **授权管理** | license_validator_py（外部依赖） |
| **目标平台** | x86 开发机 + ARM 板端（瑞芯微 RK3588 等） |
| **支持部位** | 背部（BP004）、腹部（BP014）、腿部（BP010） |
| **通信接口** | ROS 2 Service (`/visual/recognize_acupoint`) + Topic (`/visual_recognize/states`) |

## 错误码说明

| 错误码 | 含义 |
|---|---|
| `0` | 识别成功 |
| `-1` | 底层识别异常（统一错误码） |
| `-11` | 不支持的 body_part_code |
| `-13` | 识别算法调用异常（ROS 节点层） |
| `-99` | 无法解码图像数据 |
