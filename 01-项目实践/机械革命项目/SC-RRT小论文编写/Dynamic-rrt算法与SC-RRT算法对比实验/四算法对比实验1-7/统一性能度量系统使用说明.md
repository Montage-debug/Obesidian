# 统一性能度量系统使用说明

## 概述

本系统为RRT算法性能对比实验提供统一的度量标准和数据记录功能，专为论文写作设计。

## 核心度量标准

### 1. 收敛时间 (Convergence Time)
- **定义**: 算法获得首个可行解所需的计算时长（秒）
- **测量方式**: 
  - **SC-RRT**: 记录first_solution_iter，按迭代比例估算时间
  - **基础算法**: 首次找到路径的时间即为收敛时间
- **论文表述**: "收敛时间"、"首次可行解时间"

### 2. 路径代价 (Path Cost)
- **定义**: 从起始状态到目标状态的累计代价（路径长度）
- **计算方法**: 路径中相邻节点间欧氏距离之和
- **论文表述**: "路径代价"、"路径长度"（两者等价）

### 3. 计算时间 (Planning Time)
- **定义**: 算法总运行时间（秒）
- **说明**: 包括首次找到解的时间以及后续优化时间（如RRT*）
- **论文表述**: "计算时间"、"总时间"

## 使用方法

### 方法1: 使用 batchCompareAlgorithms（推荐）

批量对比多个算法，自动生成论文所需的所有数据和图表。

```matlab
% 基础使用 - 2D环境对比
results = batchCompareAlgorithms(20, 5000, ...
    'Algorithms', {'RRT_Basic', 'RRT_Star_Basic', 'SC_RRT_Basic'}, ...
    'Dimension', '2D', ...
    'NumObstacles', 30);

% 3D环境对比
results = batchCompareAlgorithms(20, 5000, ...
    'Algorithms', {'RRT_Basic', 'RRT_Star_Basic', 'SC_RRT_Basic'}, ...
    'Dimension', '3D', ...
    'NumObstacles', 20);

% 自定义输出目录
results = batchCompareAlgorithms(20, 5000, ...
    'OutputDir', 'paper_results', ...
    'SaveResults', true);
```

**生成的文件**:
- `comparison_2D_[时间戳].mat` - 完整数据（MATLAB格式）
- `comparison_2D_[时间戳].csv` - 统计数据（表格格式）
- `unified_metrics_2D_[时间戳].mat` - 统一度量数据（论文专用）
- `unified_metrics_2D_[时间戳].csv` - 统一度量CSV（论文表格）
- `chart_*.png` - 对比图表

### 方法2: 使用 UnifiedMetricsRecorder

单独记录实验数据，适合自定义实验流程。

```matlab
% 创建记录器
recorder = UnifiedMetricsRecorder('2D');

% 运行算法并记录
env = generate2DEnvironment([0 100 0 100], 20);

% 记录RRT_Basic
tic;
[path1, tree1, success1] = RRT_Basic(env, 5000);
time1 = toc;
recorder.recordAlgorithmRun('RRT_Basic', env, path1, tree1, success1, time1);

% 记录SC-RRT（包含metrics）
tic;
[path2, tree2, success2, metrics2] = SC_RRT_Basic(env, 5000);
time2 = toc;
recorder.recordAlgorithmRun('SC_RRT', env, path2, tree2, success2, time2, metrics2);

% 导出数据
recorder.exportToMAT('my_experiment.mat');
recorder.exportToCSV('my_experiment.csv');
recorder.printSummary();
```

## 关键术语对照

| 代码中的术语 | 论文中的表述 | 说明 |
|------------|------------|-----|
| convergence_time | 收敛时间 | 首次找到可行解的时间 |
| path_cost / path_length | 路径代价 / 路径长度 | 累计欧氏距离，两者等价 |
| planning_time | 计算时间 / 总时间 | 算法总运行时间 |
| tree_nodes | 树节点数 | 生成的搜索树节点总数 |
| success_rate | 成功率 | 找到可行解的比例 |
| smoothness | 平滑度 | 路径角度变化的标准差 |

## 注意事项

1. **不修改基础算法**: 本系统仅在数据记录层统一度量标准，不修改RRT、RRT*、RRT-Connect等基础算法的实现

2. **收敛时间说明**:
   - 基础算法（RRT、RRT*等）首次找到解即停止或继续优化
   - SC-RRT会持续优化，首次找到解的时间通过迭代比例估算
   - 论文中应说明收敛时间的定义

3. **路径代价说明**:
   - 必须是累计欧氏距离，不是直线距离
   - RRT*可能在后续迭代中优化路径代价
   - SC-RRT包含平滑优化，路径代价可能略有增加

4. **多次运行**: 建议每个算法至少运行20次，报告均值±标准差

5. **环境一致性**: 批量对比时使用相同的随机种子和环境配置

## 示例实验脚本

```matlab
% 完整的论文实验脚本
% 作者: [你的名字]
% 日期: 2025-12-13

%% 设置
clear; clc; close all;

% 实验参数
num_runs = 20;           % 每个算法运行20次
max_iterations = 5000;   % 最大迭代次数
algorithms = {'RRT_Basic', 'RRT_Star_Basic', 'SC_RRT_Basic'};

%% 实验1: 2D环境，不同障碍物密度
obstacle_counts = [10, 20, 30, 40];

for i = 1:length(obstacle_counts)
    fprintf('========== 实验1-%d: 2D环境, %d个障碍物 ==========\n', i, obstacle_counts(i));
    
    results = batchCompareAlgorithms(num_runs, max_iterations, ...
        'Algorithms', algorithms, ...
        'Dimension', '2D', ...
        'NumObstacles', obstacle_counts(i), ...
        'OutputDir', sprintf('paper_results/2D_obs%d', obstacle_counts(i)));
end

%% 实验2: 3D环境对比
fprintf('========== 实验2: 3D环境对比 ==========\n');

results = batchCompareAlgorithms(num_runs, max_iterations, ...
    'Algorithms', algorithms, ...
    'Dimension', '3D', ...
    'NumObstacles', 20, ...
    'OutputDir', 'paper_results/3D_comparison');

fprintf('\n实验完成! 结果已保存到 paper_results/ 目录\n');
```
