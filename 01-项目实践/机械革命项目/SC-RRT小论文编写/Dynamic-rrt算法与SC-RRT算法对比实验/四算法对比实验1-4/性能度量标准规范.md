## 1. 核心性能指标定义

### 1.1 收敛时间 (Convergence Time)
- **标准定义**: 算法获得首个可行解所需的计算时长（秒）
- **测量方法**: 
  - 在算法开始前调用 `tic`
  - 在首次找到可行路径时记录 `first_solution_time = toc`
  - 对于持续优化的算法（如RRT*），记录两个时间：
    - `convergence_time`: 首个可行解时间
    - `planning_time`: 总计算时间
- **变量命名**: `convergence_time` (首次可行解), `planning_time` (总时间)
- **单位**: 秒 (s)
- **注意事项**: 
  - 收敛时间必须在首次成功连接起点和终点时立即记录
  - 对于未找到解的情况，收敛时间为 `inf` 或 `NaN`

### 1.2 路径代价 (Path Cost)
- **标准定义**: 从起始状态到目标状态的累计代价（路径长度）
- **测量方法**:
  ```matlab
  % 计算路径累计代价
  path_cost = 0;
  for i = 1:size(path, 1)-1
      path_cost = path_cost + norm(path(i+1, :) - path(i, :));
  end
  ```
- **变量命名**: `path_cost` 或 `path_length`
- **单位**: 距离单位（与环境坐标系统一致）
- **注意事项**:
  - 必须计算路径中相邻节点间的实际欧氏距离之和
  - 不可使用起点到终点的直线距离
  - 对于未找到路径的情况，路径代价为 `inf`

### 1.3 其他性能指标
- **迭代次数** (`iterations`): 实际执行的迭代次数
- **树节点数** (`tree_nodes`): 生成的树节点总数（双向算法需要统计两棵树）
- **成功率** (`success_rate`): 成功找到路径的比例 (0或1，批量实验中统计)
- **平滑度** (`smoothness`): 路径角度变化的标准差
- **安全间隙** (`clearance`): 路径与障碍物的平均最小距离

## 2. 各算法实现要求

### 2.1 RRT_Basic
```matlab
% 在算法开始时
tic;

% 在找到首个可行解时（第一次 success = true）
convergence_time = toc;
first_solution_found = true;

% 算法结束时
planning_time = toc;

% 计算路径代价
tree.path_cost = sum(vecnorm(diff(path), 2, 2));
tree.convergence_time = convergence_time;
tree.planning_time = planning_time;
```

### 2.2 RRT_Star_Basic
```matlab
% 记录首次找到解的时间
if ~first_solution_found && success
    convergence_time = toc;
    first_solution_found = true;
end

% 继续优化...

% 最终路径代价从树的cost字段获取
tree.path_cost = tree.cost(goal_node_idx);
tree.convergence_time = convergence_time;
tree.planning_time = toc;
```

### 2.3 RRT_Connect_Basic
```matlab
% 双向算法：在两棵树首次连接成功时记录
if reached && ~first_solution_found
    convergence_time = toc;
    first_solution_found = true;
end

% 路径代价需要计算两段路径之和
tree.path_cost = sum(vecnorm(diff(path), 2, 2));
```

### 2.4 SC_RRT_Basic
```matlab
% 已正确实现：
% - 使用 first_solution_iter 跟踪首次找到解
% - metrics.planning_time 记录总时间
% - metrics.path_length 记录路径代价

% 需要添加：
metrics.convergence_time = convergence_time;  % 首次找到解的时间
```

## 3. 性能数据记录标准

### 3.1 Metrics结构体标准格式
```matlab
metrics = struct();
metrics.algorithm_name = 'XXX';           % 算法名称
metrics.success = true/false;             % 是否成功
metrics.convergence_time = 0.123;         % 收敛时间(秒) - 首次可行解
metrics.planning_time = 0.456;            % 总计算时间(秒)
metrics.path_cost = 123.45;               % 路径代价
metrics.path_length = 123.45;             % 路径长度（同path_cost）
metrics.iterations = 1234;                % 迭代次数
metrics.tree_nodes = 2345;                % 树节点数
metrics.smoothness = 0.12;                % 平滑度
metrics.clearance = 5.67;                 % 安全间隙
metrics.timestamp = datetime('now');      % 记录时间
```

### 3.2 数据保存规范
- **单次运行数据**: 保存到 `results/[算法名]_[维度]_[时间戳]_data.mat`
- **批量对比数据**: 保存到 `results/performance_data_[时间戳].mat`
- **CSV导出**: 保存到 `results/performance_summary_[时间戳].csv`

## 4. 论文报告标准

### 4.1 表格数据格式
| 算法 | 成功率(%) | 收敛时间(s) | 路径代价 | 树节点数 | 平滑度 |
|------|----------|------------|---------|---------|--------|
| RRT  | 95.0 | 0.123±0.045 | 234.5±12.3 | 1234±234 | 0.15±0.03 |
| RRT* | 98.0 | 0.234±0.056 | 198.7±8.9  | 2345±345 | 0.12±0.02 |
| SC-RRT | 99.0 | 0.156±0.034 | 189.3±7.2 | 1567±189 | 0.10±0.02 |

### 4.2 关键术语
- **收敛时间**: 首次可行解计算时长
- **路径代价**: 路径累计欧氏距离
- **计算时间**: 总算法运行时间
- **路径长度**: 等同于路径代价

## 5. 注意事项

1. **时间测量**: 使用MATLAB的 `tic/toc` 机制，确保在相同条件下测量
2. **路径代价**: 必须使用累计欧氏距离，不可简化
3. **统计分析**: 批量实验中至少运行20次，报告均值和标准差
4. **环境一致性**: 同一批次实验必须使用相同的随机种子和环境配置
5. **数据完整性**: 记录所有指标，即使部分不用于论文
