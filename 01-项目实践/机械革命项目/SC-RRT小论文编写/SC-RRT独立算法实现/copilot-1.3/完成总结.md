# SC-RRT算法PID采样控制改进 - 完成总结

## 一、改进概述

### 核心变革
将PID控制从"调节节点代价函数"转变为"控制采样分布"，实现真正的闭环自适应控制。

### 理论优势
- **明确的被控量**：窗口统计的路径改进效率（物理意义清晰）
- **稳定的测量**：滑动窗口 + EMA平滑消除噪声
- **有意义的积分**：累积改进不足推动持续探索
- **有效的微分**：滤波后反映改进趋势变化

## 三、技术细节

### 3.1 PID控制方程

**测量量**（改进效率）：
$$y_k = \text{clip}\left(\frac{c_{\text{old}} - c_{\text{current}}}{c_{\text{old}} + \epsilon}, 0, 1\right)$$

**平滑**：
$$\bar{y}_k = \rho_y \bar{y}_{k-1} + (1-\rho_y) y_k$$

**误差**：
$$e_k = y^* - \bar{y}_k$$

**PID输出**：
$$u_k = K_p e_k + K_i I_k + K_d d_k$$

**映射到控制量**：
$$\gamma_k = \gamma_0 \cdot \exp(\alpha_\gamma u_k), \quad \gamma_k \in [\gamma_{\min}, \gamma_{\max}]$$
$$p_k = p_0 - \alpha_p \tanh(u_k), \quad p_k \in [p_{\min}, p_{\max}]$$

### 3.2 默认参数

| 参数 | 值 | 说明 |
|------|-----|------|
| WindowSize (W) | 50 | 滑动窗口大小 |
| TargetEfficiency (y*) | 0.02 | 目标改进率（2%） |
| Kp, Ki, Kd | 2.0, 0.2, 0.8 | PID增益 |
| ρ_y, ρ_d | 0.9, 0.8 | 平滑/滤波系数 |
| γ_min, γ_max | 1.0, 4.0 | 膨胀系数范围 |
| p_min, p_max | 0.2, 0.95 | 采样概率范围 |
| γ_0, α_γ | 1.5, 0.5 | 膨胀映射参数 |
| p_0, α_p | 0.8, 0.5 | 概率映射参数 |


- `gamma`：椭球体膨胀系数（越大采样范围越大）
- `p`：知情采样概率（越大越倾向开发）
- `y`：平滑后的改进效率

## 五、对比分析

| 特性 | 旧架构（代价调制） | 新架构（采样控制） |
|------|-------------------|-------------------|
| **PID控制对象** | 节点代价 F̂ | 采样分布 (γ, p) |
| **被控量** | 单节点误差 | 窗口改进率 |
| **测量稳定性** | ❌ 噪声大 | ✅ 平滑稳定 |
| **积分项意义** | ❌ 模糊 | ✅ 累积改进不足 |
| **微分项效果** | ❌ 震荡严重 | ✅ 滤波有效 |
| **闭环反馈** | ❌ 弱（间接影响） | ✅ 强（直接控制） |
| **物理解释** | ❌ 不直观 | ✅ 清晰明确 |
| **参数鲁棒性** | ❌ 易震荡/饱和 | ✅ 调参友好 |
