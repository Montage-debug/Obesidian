# SC-RRT算法：自适应双向超椭球体工作流程图

## 概述

本文档描述SC-RRT（Sampling-Constrained RRT）算法中自适应双向超椭球体采样约束机制的完整工作流程。核心思想是通过动态交汇点和双椭球体约束实现高效的双向搜索空间收敛。

---

## 整体流程图

```mermaid
flowchart TD
    Start([开始: 初始化双树]) --> Init[初始化状态]
    Init --> MainLoop{迭代循环<br/>iter < maxIter}
    
    MainLoop -->|每updateInterval次| UpdateMeet[更新交汇点与双椭球]
    MainLoop -->|每次迭代| SampleA[树A采样]
    
    UpdateMeet --> CalcMeet[势场法计算新交汇点]
    CalcMeet --> SmoothMeet[平滑更新交汇点]
    SmoothMeet --> CalcEllipsoid[计算双椭球体参数]
    CalcEllipsoid --> PID[PID控制器更新]
    PID --> Visualize[可视化双椭球体]
    Visualize --> SampleA
    
    SampleA --> ExpandA[扩展树A]
    ExpandA --> SampleB[树B采样]
    SampleB --> ExpandB[扩展树B]
    ExpandB --> CheckConnect{检查连接}
    
    CheckConnect -->|成功| PathFound[路径找到]
    CheckConnect -->|失败| MainLoop
```

## 核心模块详细流程

### 1. 交汇点更新流程

```mermaid
flowchart TD
    Start([触发条件: mod_iter_updateInterval_==0]) --> CalcCentroid[计算有效质心]
    
    CalcCentroid --> CentroidA[树A有效质心<br/>选择前30%低代价节点]
    CalcCentroid --> CentroidB[树B有效质心<br/>选择前30%低代价节点]
    
    CentroidA --> CalcWeight[计算动态权重]
    CentroidB --> CalcWeight
    
    CalcWeight --> Formula["meetPoint_new = <br/>weightA × centroidB + <br/>weightB × centroidA"]
    
    Formula --> Smooth["平滑更新:<br/>meetPoint = α × meetPoint_old + <br/>_1-α_ × meetPoint_new"]
    
    Smooth --> Clamp[边界裁剪<br/>限制在起点-终点范围内]
    
    Clamp --> Output([输出: 新交汇点])
    
    style CalcCentroid fill:#e8f4f8
    style Formula fill:#fff9e6
    style Smooth fill:#f0e6ff
```

**关键参数：**
- `α`（smoothingFactor）：平滑系数，默认0.7，防止交汇点振荡
- 权重计算：`weightA = sizeA / (sizeA + sizeB)`

---

### 2. 双椭球体参数计算流程

```mermaid
flowchart TD
    Start([输入: treeA, treeB, <br/>startPoint, goalPoint, meetPoint]) --> CalcFocal[计算焦距]
    
    CalcFocal --> FocalA["c_min_A = ||meetPoint - startPoint||"]
    CalcFocal --> FocalB["c_min_B = ||goalPoint - meetPoint||"]
    
    FocalA --> TraverseA[遍历树A]
    FocalB --> TraverseB[遍历树B]
    
    TraverseA --> ComputeFA["对每个节点i计算:<br/>F_i = G_i + H_i_meet_<br/>G_i: 起点到i的代价<br/>H_i: i到交汇点距离"]
    
    TraverseB --> ComputeFB["对每个节点j计算:<br/>F_j = G_j + H_j_meet_<br/>G_j: 终点到j的代价<br/>H_j: j到交汇点距离"]
    
    ComputeFA --> FindMinA["c_best_A = min_F_i_"]
    ComputeFB --> FindMinB["c_best_B = min_F_j_"]
    
    FindMinA --> Buffer[应用缓冲系数]
    FindMinB --> Buffer
    
    Buffer --> BufferCalc["c_best_A = max_c_best_A, c_min_A × buffer_<br/>c_best_B = max_c_best_B, c_min_B × buffer_"]
    
    BufferCalc --> Validate[验证交集可达性]
    
    Validate --> Check{"c_best_A + c_best_B <br/> ≥ ||start - goal||?"}
    
    Check -->|否| Adjust[比例调整确保交集]
    Check -->|是| Output([输出: 双椭球体参数<br/>c_best_A, c_best_B, <br/>c_min_A, c_min_B])
    
    Adjust --> Output
    
    style CalcFocal fill:#e8f4f8
    style ComputeFA fill:#fff4e1
    style ComputeFB fill:#fff4e1
    style Buffer fill:#e1ffe8
```

**椭球体定义：**
- **椭球体A**：焦点为`(startPoint, meetPoint)`，半长轴`a = c_best_A / 2`
- **椭球体B**：焦点为`(meetPoint, goalPoint)`，半长轴`a = c_best_B / 2`
- **缓冲系数**：默认1.2，防止过小椭球导致采样困难

---

### 3. PID控制器更新流程（简化）

```mermaid
flowchart TD
    Start([输入: 当前最优代价 L_best]) --> UpdateHist[更新代价历史]
    
    UpdateHist --> CalcEfficiency["计算改进效率:<br/>y_k = Δc / window"]
    
    CalcEfficiency --> CalcError["计算误差:<br/>e_k = target_efficiency - y_k"]
    
    CalcError --> PIDCore[PID控制器核心计算]
    
    PIDCore --> ProportionalTerm["P项: K_p × e_k"]
    PIDCore --> IntegralTerm["I项: K_i × Σe"]
    PIDCore --> DerivativeTerm["D项: K_d × Δe"]
    
    ProportionalTerm --> SumPID["u_k = P + I + D"]
    IntegralTerm --> SumPID
    DerivativeTerm --> SumPID
    
    SumPID --> UpdateGamma["更新膨胀系数:<br/>γ ← clamp_γ_min, γ_max_"]
    SumPID --> UpdateP["更新知情采样概率:<br/>p ← clamp_p_min, p_max_"]
    
    UpdateGamma --> Output([输出: γ, p_informed])
    UpdateP --> Output
    
    style PIDCore fill:#ffe1e1
    style CalcEfficiency fill:#e1f5ff
    style Output fill:#e1ffe8
```

**PID控制逻辑：**
- **改进缓慢**（`e_k > 0`）→ 增大`γ`，减小`p` → **增强探索**
- **改进顺利**（`e_k < 0`）→ 减小`γ`，增大`p` → **加强开发**

---

### 4. 知情采样流程

```mermaid
flowchart TD
    Start([开始采样]) --> Decision{"rand < p_informed<br/>且椭球有效?"}
    
    Decision -->|是| InformedSample[知情采样：椭球内采样]
    Decision -->|否| UniformSample[全局采样：空间均匀采样]
    
    InformedSample --> CalcEllipse[计算膨胀椭球参数]
    
    CalcEllipse --> Params["半长轴: a = γ × c_best / 2<br/>半焦距: c = c_min / 2<br/>半短轴: b = sqrt_a² - c²_"]
    
    Params --> CalcCenter["椭球中心:<br/>center = _start + goal_ / 2"]
    
    CalcCenter --> CalcRotation["计算旋转矩阵R:<br/>将标准椭球旋转到<br/>start→goal方向"]
    
    CalcRotation --> SampleUnit[单位球内均匀采样]
    
    SampleUnit --> Transform["变换到椭球空间:<br/>sample = center + R × S × p<br/>S = diag_a, b, b_"]
    
    Transform --> ValidateSample{碰撞检测}
    
    UniformSample --> ValidateUniform{碰撞检测}
    
    ValidateSample -->|无碰撞| Output([输出: 有效采样点])
    ValidateSample -->|有碰撞| MaxRetry{达到最大<br/>重试次数?}
    
    ValidateUniform -->|无碰撞| Output
    ValidateUniform -->|有碰撞| Output
    
    MaxRetry -->|否| SampleUnit
    MaxRetry -->|是| FallbackUniform[降级为全局采样]
    FallbackUniform --> Output
    
    style InformedSample fill:#e1f5ff
    style UniformSample fill:#fff4e1
    style Transform fill:#e1ffe8
```

**关键点：**
- `γ`（gamma）：椭球膨胀系数，由PID控制，范围`[1.0, 4.0]`
- `p_informed`：知情采样概率，由PID控制，范围`[0.2, 0.95]`

### 5. 完整双向扩展流程

```mermaid
flowchart TD
    Start([主循环开始]) --> CheckUpdate{"mod_iter, interval_ == 0?"}
    
    CheckUpdate -->|是| UpdateBlock[交汇点与双椭球更新模块]
    CheckUpdate -->|否| TreeA
    
    UpdateBlock --> CalcMeetPoint[势场法计算交汇点]
    CalcMeetPoint --> CalcDualEllipsoid[计算双椭球体参数]
    CalcDualEllipsoid --> UpdatePID[PID控制器更新]
    UpdatePID --> TreeA
    
    TreeA[树A扩展] --> SampleA["采样点 x_rand<br/>_知情或全局_"]
    SampleA --> NearestA["找最近节点 x_near"]
    NearestA --> SteerA["扩展: x_new = steer_x_near, x_rand_"]
    SteerA --> CollisionA{碰撞检测}
    
    CollisionA -->|无碰撞| AddNodeA[添加节点到树A]
    CollisionA -->|有碰撞| TreeB
    
    AddNodeA --> TreeB
    
    TreeB[树B扩展] --> SampleB["采样点 x_rand<br/>_知情或全局_"]
    SampleB --> NearestB["找最近节点 x_near"]
    NearestB --> SteerB["扩展: x_new = steer_x_near, x_rand_"]
    SteerB --> CollisionB{碰撞检测}
    
    CollisionB -->|无碰撞| AddNodeB[添加节点到树B]
    CollisionB -->|有碰撞| CheckConnect
    
    AddNodeB --> CheckConnect
    
    CheckConnect{尝试连接双树} --> ConnectDist["dist_treeA, treeB_ < threshold?"]
    
    ConnectDist -->|是| PathFound[路径找到，成功退出]
    ConnectDist -->|否| Continue{达到最大迭代?}
    
    Continue -->|否| Start
    Continue -->|是| Failed[搜索失败]
    
    PathFound --> End([结束])
    Failed --> End
    
    style UpdateBlock fill:#e1f5ff
    style TreeA fill:#fff4e1
    style TreeB fill:#ffe1f5
    style PathFound fill:#e1ffe8
```

## 关键参数汇总

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `updateInterval` | 50 | 交汇点更新间隔（迭代次数） |
| `smoothingFactor` | 0.7 | 交汇点平滑系数α |
| `ellipsoidBuffer` | 1.2 | 椭球体缓冲系数 |
| `gamma` | 1.0~4.0 | 椭球膨胀系数（PID控制） |
| `p_informed` | 0.2~0.95 | 知情采样概率（PID控制） |

## 自适应机制说明

### 1. 动态交汇点转移
- **目的**：引导双树向潜在最优连接点收敛
- **方法**：势场法计算有效质心，动态权重加权
- **优势**：避免盲目双向扩展，提高搜索效率

### 2. 非对称双椭球约束
- **椭球体A**：约束树A向交汇点扩展
- **椭球体B**：约束树B向交汇点扩展
- **非对称性**：两椭球体参数独立计算，适应不同搜索进度

### 3. PID自适应采样控制
- **被控量**：路径改进效率
- **控制量**：椭球膨胀系数γ、知情采样概率p
- **效果**：根据搜索效果自动平衡"探索"与"开发"

---

## 算法优势

1. **高效收敛**：双椭球体约束聚焦有效搜索空间
2. **自适应性**：PID控制动态调节采样策略
3. **双向协同**：交汇点机制引导双树高效对接
4. **鲁棒性强**：平滑更新和缓冲机制防止震荡
