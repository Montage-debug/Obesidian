# SC-RRT PID参数实验 - 整理后干净环境

## 概述

尊敬的研究生大人，本实验项目专注于SC-RRT（Self-Constrained RRT）算法中PID参数对路径规划性能的影响研究。实验已完成清理，移除了说明文档、测试脚本和历史日志，提供干净的实验空间。

## 实验配置

### 障碍物配置（已调整至您指定要求）

- **二维场景**：1500×1500，225个障碍物（半径22-38，自适应缩放以确保放置达标）
- **三维场景**：1500×1500×1500，400个障碍物（半径35-55，自适应缩放以确保放置达标）

### 迭代次数配置（可根据需要调整）

- **稳定性预评估模式**（默认）：
  - 二维：900次迭代
  - 三维：1200次迭代
  - 重复次数：6次/配置
  - 预计耗时：6-10分钟

- **标准实验模式**：
  - 二维：1200次迭代
  - 三维：1500次迭代
  - 重复次数：12次/配置
  - 预计耗时：25-35分钟

### 自适应障碍物放置

环境生成模块增加了自动调整半径的功能，以确保高密度障碍物场景能够稳定放置：

- 如障碍物数量未达标，会自动缩小半径范围（缩放因子0.92）
- 最多6轮自适应调整
- 确保障碍物数量满足要求的同时，避免放置失败

## 运行指南

### 1. 自适应控制对比实验（推荐）

```bash
python run_adaptive_experiment.py --baseline
```

- 运行小规模对比实验
- 对比有/无自适应控制器的性能差异
- 若结果稳定，可考虑扩大实验规模

### 2. 查看稳定性评估结果

实验完成后，检查输出的稳定性评估提示：
- **[STABLE]**：当前结果稳定，可考虑扩大实验规模（提高重复次数）
- **[NOT STABLE]**：当前结果未达稳定阈值，建议先保持小规模验证

### 3. 扩大实验规模（确认稳定后）

修改 `experiments/run_pid_experiment.py` 中的配置：
- 将 `self.num_trials` 从6提升至12或30
- 确保计算资源充足

### 4. 其他运行模式

```bash
# 精细化参数搜索
python run_local_pid_experiment.py --refine

# 三参数调优
python run_local_pid_experiment.py --finetune

# 完整实验
python run_local_pid_experiment.py
```

## 实验指标说明

### 三层评价体系

1. **成功率**（第一层）：筛选达到阈值的PID配置
2. **路径质量**（第二层）：在成功样本中比较平均路径长度、路径效率
3. **综合排序**（第三层）：成功率 > 路径长度 > 路径效率 > 树节点数

### 核心采样效率指标

- **有效采样比例（ESR）**：证明PID引导采样进入约束区域
- **Sample-to-Success**：证明PID提高单位采样价值

## 注意事项

- 首次运行建议使用稳定性预评估模式，确认配置可靠后再扩大规模
- 自适应障碍物放置功能会自动调整半径，确保满足指定数量
- 迭代次数可根据成功率调整：若成功率过低，增加迭代次数；若过高，减少迭代次数
