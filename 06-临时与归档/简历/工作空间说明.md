# ASu 简历工作空间

这里保存可编辑简历、历史材料、本地技能与后续版本。后续在这个目录继续任务即可；换到其他目录时，请先让助手读取本目录的 `AGENTS.md`。工作空间入口采用 [Codex 官方 AGENTS.md 机制](https://learn.chatgpt.com/docs/agent-configuration/agents-md)。

## 直接这样用

- “/asu 按下面的 ROS2 岗位 JD，改写我的项目经历和 HR 开场白。”
- “/asu-resume 基于当前简历做一版嵌入式方向，保留版式，输出可编辑 HTML 和 PDF。”
- “把语音交互项目新增的这些成果补进去，只改这一段。”
- “/resume 改成一页，先保证信息完整与可读。”
- “/offer 记录这次投递和下一步面试时间。”

通常给出目标岗位/JD、新增或更正的事实、希望交付的格式就够了。已有信息从材料中读取，只补问会影响结果的缺口。

## 文件职责

- `workspace-state.json`：当前编辑基线、已有 PDF 与已知待核对项。
- 根目录现有 HTML：目前默认编辑起点；已有 PDF 尚未做内容对应及版式验收。
- `源/`：历次和不同方向的 DOCX/PDF。按岗位查阅，不直接覆盖。
- `备份/`：已有备份；其中同名 HTML 与根目录版本内容不同，不自动替换当前稿。
- `assets/resume/`：现有简历引用的证件照；根目录照片与这里的照片当前内容相同。
- `skills/`：本地维护的 5 个技能。`AGENTS.md` 负责按需路由。
- `scripts/resume_workspace.py`：只读自检，以及为当前 HTML 创建隔离的新版本。
- `版本/`：运行创建命令后生成，每版附带 `版本说明.md`。

## 创建新版本

有 Python 3.10+ 时，在本目录运行：

```powershell
python scripts/resume_workspace.py check
python scripts/resume_workspace.py new --direction ROS2 --date 2026-09-09
```

如果系统没有 `python` 命令，助手可先通过 `load_workspace_dependencies` 获取本机捆绑 Python 路径，再执行脚本。脚本仅使用标准库。

创建命令从已登记基线复制成 `版本/日期-方向-vNN/resume.html`，将本地照片嵌入副本，分离浏览器内容与页面模式保存键，并写入版本说明。它不会改写简历内容、自动修复分页或生成 PDF。每次复制以磁盘 HTML 为准，不包含仅保存在浏览器里的改动。

当前脚本针对现有单页编辑器结构；遇到不同脚本/存储结构会停止并说明原因，避免生成混用缓存的副本。换模板后需同步调整脚本。

## 每次迭代留下什么

在当版 `版本说明.md` 记录：目标岗位与 JD 来源、使用的源文件、修改要点、关键事实及证据、待确认项、HTML/打印/PDF 检查结果。保留 HTML 和最终 PDF；如仅修改文案，不强制生成文件或 HR 话术。

浏览器“自动保存”目前只写浏览器本地存储，不会修改磁盘 HTML。需要把手工编辑纳入下一版时，应先导出实际内容或让助手帮助写回文件。PDF 导出前检查 A4、页眉页脚关闭、背景图形、分页和内容完整性。
