在Terminator里设置主机名、用户名和文件目录的颜色，主要是通过修改Shell的**PS1变量**来实现的。同时，你也可以在Terminator的配置文件中调整终端的整体色彩风格。下面是一个配置示例，直观展示了修改后的效果：

```bash
# 示例PS1配置，按你的喜好修改颜色代码即可
export PS1="\[\e[1;35m\]\u\[\e[0m\]@\[\e[1;36m\]\h\[\e[0m\]:\[\e[1;32m\]\w\[\e[0m\]\$ "
```

### 🎨 认识PS1变量与颜色代码

**PS1（Prompt String 1）** 是控制主提示符格式的环境变量。颜色设置遵循 `\[\e[F;Bm\]...\[\e[0m\]` 的格式：
- `F` 代表**字体颜色**（30-37）
- `B` 代表**背景颜色**（40-47）
- `\[\e[0m\]` 用于结束颜色设置

下面这个表格列出了常用的颜色代码，方便你查阅和组合：

| 字体色(F) | 背景色(B) | 代表颜色 |
| :--- | :--- | :--- |
| 30 | 40 | 黑色 |
| 31 | 41 | **红色** |
| 32 | 42 | **绿色** |
| 33 | 43 | **黄色** |
| 34 | 44 | **蓝色** |
| 35 | 45 | **紫红色** |
| 36 | 46 | **青蓝色** |
| 37 | 47 | 白色 |

**常用转义序列**：
- `\u`：当前**用户名**
- `\h`：**主机名**的第一个名字
- `\w`：完整的**工作目录**名称
- `\H`：完整的主机名
- `\W`：仅显示当前目录的最后一部分

### ⚙️ 配置方法与步骤

#### **方法一：通过修改 `~/.bashrc` 文件（永久生效）**

这是最常用和推荐的方法。

1.  **打开配置文件**：在终端中输入：
    ```bash
    nano ~/.bashrc
    ```
2.  **添加PS1变量**：在文件末尾添加你的PS1配置。例如，下面的配置实现了：
    - **用户名**为紫色（35）
    - **主机名**为青蓝色（36）
    - **当前目录**为绿色（32）

    ```bash
    # 设置Terminator提示符颜色
    export PS1="\[\e[1;35m\]\u\[\e[0m\]@\[\e[1;36m\]\h\[\e[0m\]:\[\e[1;32m\]\w\[\e[0m\]\$ "
    ```
3.  **使配置生效**：保存并退出编辑器（在nano中按 `Ctrl+X`，然后按 `Y` 确认），然后运行以下命令使配置立即生效：
    ```bash
    source ~/.bashrc
    ```

#### **方法二：在Terminator配置文件中设置全局外观**

这个方法主要调整终端的整体配色方案（背景、字体、光标色等），可以和PS1的配置结合使用。

1.  **打开Terminator配置文件**：
    ```bash
    nano ~/.config/terminator/config
    ```
2.  **修改颜色配置**：找到 `[profiles]` 部分下的 `[[default]]` 子节，添加或修改如下颜色设置：
    ```ini
    [profiles]
      [[default]]
        # 背景颜色
        background_color = "#2d2d2d"
        # 终端文字颜色
        foreground_color = "#eeeeee"
        # 光标颜色
        cursor_color = "#ffffff"
        # 是否使用系统字体
        use_system_font = False
        # 自定义字体和大小
        font = Ubuntu Mono 13
        # 可选：隐藏标题栏，让界面更简洁
        show_titlebar = False
    ```
    修改后，保存并退出。**重启Terminator**后这些设置就会生效。

### 🔧 实用技巧与注意事项

- **快速测试**：你可以直接在终端命令行中临时输入 `export PS1="..."` 来预览效果，满意后再写入 `~/.bashrc` 文件。
- **恢复默认**：如果配置出错，只需删除 `~/.bashrc` 中添加的PS1行，然后执行 `source ~/.bashrc` 即可恢复默认设置。
- **"选中即复制"**：在Terminator的偏好设置中，可以开启 "**Copy on selection**" 选项。这样你只需用鼠标选中文本，它就自动复制到了剪贴板，按 `Ctrl+Shift+V` 即可粘贴。
- **配置文件位置**：Terminator 的主配置文件通常位于 `~/.config/terminator/config`。如果找不到，可以右键点击 Terminator 内部，选择 **Preferences**，然后进行设置，它通常会自动生成该文件。
