# Vim 编辑器完全指南

## 1. 模式介绍
Vim 有多种工作模式，这是其强大功能的基石：

| 模式 | 进入方式 | 退出方式 | 用途 |
|------|----------|----------|------|
| **普通模式** | 按 `Esc` | 自动进入 | 执行命令、移动光标 |
| **插入模式** | `i`, `I`, `a`, `A`, `o`, `O` | `Esc` | 插入文本 |
| **可视模式** | `v`, `V`, `Ctrl+v` | `Esc` | 选择文本块 |
| **命令模式** | `:` | `Enter` 执行后自动退出 | 执行ex命令 |
| **替换模式** | `R` | `Esc` | 替换字符 |

## 2. 启动与退出

### 启动Vim
```bash
vim [文件名]           # 打开文件
vim +n [文件名]        # 打开并跳转到第n行
vim +/pattern [文件名] # 打开并搜索pattern
vim -o [文件1] [文件2] # 水平分割打开多个文件
vim -O [文件1] [文件2] # 垂直分割打开多个文件
```

### 保存与退出
```vim
:w              " 保存
:w [文件名]      " 另存为
:wq 或 :x 或 ZZ " 保存并退出
:q              " 退出（无修改时）
:q!             " 强制退出，不保存
:w !sudo tee %  " 无权限时保存（需要sudo权限）
```

## 3. 光标移动

### 基本移动
```
h       左
j       下
k       上
l       右
```

### 词移动
```
w       下一个单词开头
W       下一个单词开头（忽略标点）
e       当前/下一个单词结尾
E       当前/下一个单词结尾（忽略标点）
b       上一个单词开头
B       上一个单词开头（忽略标点）
```

### 行内移动
```
0       行首
^       行首第一个非空字符
$       行尾
g_      行尾最后一个非空字符
f[字符] 向后查找字符
F[字符] 向前查找字符
t[字符] 向后查找字符前一个位置
T[字符] 向前查找字符前一个位置
;       重复上次查找
,       反向重复上次查找
```

### 屏幕移动
```
Ctrl+f  向下翻页
Ctrl+b  向上翻页
Ctrl+d  向下半页
Ctrl+u  向上半页
H       屏幕顶部
M       屏幕中间
L       屏幕底部
zz      当前行居中
zt      当前行置顶
zb      当前行置底
```

### 文档移动
```
gg      文件开头
G       文件末尾
:[行号] 跳转到指定行
[行号]G 跳转到指定行
[行号]gg 跳转到指定行
Ctrl+g  显示当前位置信息
%       跳转到匹配的括号
```

### 标记与跳转
```
m[a-z]  设置标记（小写：当前文件）
m[A-Z]  设置标记（大写：跨文件）
`[标记] 跳转到标记
'[标记] 跳转到标记所在行首
``      跳转到上次位置
''      跳转到上次位置的行首
:marks  查看所有标记
```

## 4. 插入文本

### 进入插入模式
```
i       光标前插入
I       行首插入
a       光标后插入
A       行尾插入
o       下一行插入
O       上一行插入
gi      上次插入位置开始插入
```

### 特殊插入
```
Ctrl+h  删除前一个字符（插入模式）
Ctrl+w  删除前一个单词（插入模式）
Ctrl+u  删除到行首（插入模式）
Ctrl+[  等同于 Esc
Ctrl+c  等同于 Esc
```

## 5. 编辑操作

### 删除
```
x       删除当前字符
X       删除前一个字符
dw      删除单词
d$ 或 D 删除到行尾
dd      删除整行
d[移动] 删除到移动命令位置
```

### 复制（yank）
```
yy      复制整行
y$      复制到行尾
y[移动] 复制到移动命令位置
"[寄存器]y 复制到指定寄存器
```

### 粘贴
```
p       在光标后粘贴
P       在光标前粘贴
"[寄存器]p 粘贴指定寄存器的内容
```

### 撤销与重做
```
u       撤销
Ctrl+r  重做
U       撤销整行修改
```

### 更改（删除并进入插入模式）
```
cw      修改单词
c$      修改到行尾
cc      修改整行
C       修改到行尾（同c$）
s       删除字符并插入（替换单个字符）
S       删除整行并插入（同cc）
r[字符] 替换单个字符
R       进入替换模式
~       切换大小写
```

## 6. 搜索与替换

### 搜索
```
/pattern    向前搜索
?pattern    向后搜索
n           下一个匹配项
N           上一个匹配项
*           向前搜索当前单词
#           向后搜索当前单词
```

### 替换
```vim
:s/old/new           " 替换当前行第一个匹配
:s/old/new/g         " 替换当前行所有匹配
:%s/old/new/g        " 替换全文所有匹配
:%s/old/new/gc       " 替换全文，每次替换前确认
:5,10s/old/new/g     " 替换5-10行所有匹配
```

### 高级搜索模式
```
\c         忽略大小写
\C         匹配大小写
\<         单词开头
\>         单词结尾
```

## 7. 可视模式操作

### 进入可视模式
```
v       字符可视模式
V       行可视模式
Ctrl+v  块可视模式
gv      重新选择上次选区
```

### 可视模式下操作
```
d       删除选中内容
y       复制选中内容
c       修改选中内容
=       自动缩进选中内容
>       向右缩进
<       向左缩进
```

## 8. 多文件编辑

### 缓冲区（Buffer）操作
```vim
:e [文件名]       " 打开新文件到缓冲区
:bn              " 下一个缓冲区
:bp              " 上一个缓冲区
:bd              " 删除缓冲区
:ls 或 :buffers  " 列出所有缓冲区
:b [编号/部分名] " 切换到指定缓冲区
```

### 窗口（Window）操作
```vim
:sp [文件名]      " 水平分割窗口
:vsp [文件名]     " 垂直分割窗口
Ctrl+w s         " 水平分割当前窗口
Ctrl+w v         " 垂直分割当前窗口
Ctrl+w w         " 切换窗口
Ctrl+w h/j/k/l   " 向左/下/上/右切换窗口
Ctrl+w H/J/K/L   " 移动窗口到左/下/上/右
Ctrl+w =         " 使所有窗口等宽等高
Ctrl+w +         " 增加窗口高度
Ctrl+w -         " 减少窗口高度
Ctrl+w >         " 增加窗口宽度
Ctrl+w <         " 减少窗口宽度
Ctrl+w q         " 关闭当前窗口
Ctrl+w o         " 只保留当前窗口
```

### 标签页（Tab）操作
```vim
:tabnew [文件名]   " 新建标签页
:tabn 或 gt       " 下一个标签页
:tabp 或 gT       " 上一个标签页
:tabc             " 关闭当前标签页
:tabo             " 关闭其他标签页
:tabm [n]         " 移动标签页到第n位置
:tabs             " 列出所有标签页
```

## 9. 寄存器（Register）

### 寄存器类型
```
"       无名寄存器（默认）
0       最近复制的内容
1-9     删除/修改历史
a-z     命名寄存器（用户自定义）
+       系统剪贴板
*       系统选择剪贴板（X11）
%       当前文件名
:       最近执行的命令
.       最近插入的文本
```

### 使用寄存器
```
"[寄存器]y  复制到寄存器
"[寄存器]p  从寄存器粘贴
:reg [寄存器] 查看寄存器内容
```

## 10. 宏（Macro）

### 录制与使用
```
q[寄存器]   开始录制宏到寄存器
q          停止录制
@[寄存器]   执行宏
@@         重复执行上次宏
```

### 宏编辑
```
:let @[寄存器]='内容'  " 编辑宏内容
```

## 11. 折叠（Folding）

### 折叠方法
```
zf[移动]   创建折叠
zo        打开折叠
zc        关闭折叠
za        切换折叠状态
zR        打开所有折叠
zM        关闭所有折叠
zd        删除折叠
```

### 折叠类型
```vim
:set foldmethod=manual   " 手动折叠
:set foldmethod=indent   " 缩进折叠
:set foldmethod=syntax   " 语法折叠
:set foldmethod=marker   " 标记折叠
```

## 12. 实用命令

### 文件操作
```vim
:r [文件名]       " 插入文件内容
:r !命令         " 插入命令输出
:w >> [文件名]   " 追加到文件
:!命令           " 执行shell命令
```

### 编码与格式
```vim
:set fileencoding=utf-8  " 设置文件编码
:set ff=unix             " 设置换行符为Unix格式
:set ff=dos              " 设置换行符为DOS格式
:%!xxd                   " 以16进制查看
:%!xxd -r                " 从16进制恢复
```

### 帮助系统
```vim
:help             " 打开帮助
:help [主题]      " 查看特定主题帮助
Ctrl+]            " 跳转到帮助链接
Ctrl+t            " 返回帮助跳转前
:helptags [目录]  " 生成帮助标签
```

## 13. 配置与插件

### 基本配置（~/.vimrc）
```vim
" 显示设置
set number        " 显示行号
set relativenumber " 相对行号
set cursorline    " 高亮当前行
set showcmd       " 显示命令
set title         " 显示标题

" 搜索设置
set hlsearch      " 高亮搜索结果
set incsearch     " 实时搜索
set ignorecase    " 忽略大小写
set smartcase     " 智能大小写

" 编辑设置
set autoindent    " 自动缩进
set expandtab     " 用空格代替Tab
set tabstop=4     " Tab宽度
set shiftwidth=4  " 缩进宽度
set backspace=indent,eol,start " 增强退格键

" 其他设置
syntax on         " 语法高亮
set mouse=a       " 启用鼠标
```

### 插件管理器示例（vim-plug）
```vim
call plug#begin('~/.vim/plugged')
Plug 'scrooloose/nerdtree'           " 文件浏览器
Plug 'ctrlpvim/ctrlp.vim'            " 文件搜索
Plug 'vim-airline/vim-airline'       " 状态栏
Plug 'tpope/vim-surround'            " 括号/引号包围
call plug#end()
```

## 14. 快捷键速查表

### 常用组合
```
Ctrl+p       补全（插入模式）
Ctrl+n       补全（插入模式）
Ctrl+x Ctrl+f 文件名补全
Ctrl+x Ctrl+l 行补全
Ctrl+a       增加数字
Ctrl+x       减少数字
.            重复上次修改
```

### 数字前缀
任何命令前加数字表示重复次数：
```
5dd     删除5行
3p      粘贴3次
10j     向下移动10行
```

## 15. 学习建议

### 循序渐进
1. 先掌握基本移动（h,j,k,l）
2. 学习常用编辑命令（d,y,p,u）
3. 掌握搜索替换（/,:s）
4. 学习多文件操作（:sp,:bn）
5. 探索高级功能（寄存器、宏、折叠）

### 练习方法
```bash
vimtutor          # Vim自带的教程
vim -u NONE -N    # 无配置启动
```
