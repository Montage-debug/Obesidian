|文件|作用|与谁交互|
|---|---|---|
|**massage_head_manager.cpp**|ROS2 节点主逻辑，负责接收串口消息、调用解析器、发布状态、周期性查询手柄|订阅 `serial_data`、发布 `massage_head_manager` 与 `massage_head_status`|
|**protocol_parser.cpp**|负责识别协议帧、解析命令、调用当前手柄对象处理|被 `massage_head_manager.cpp` 调用|
|**massage_head_base.cpp**|各类型手柄对象实现（识别、温度、电机、LED 等）|被 `protocol_parser.cpp` 调用|
|**serial_utility.cpp**|处理字符串与字节数据转换、校验|被 `massage_head_manager.cpp` 与 `protocol_parser.cpp` 调用|
|**MassageHeadStatus.msg**|ROS 消息定义，表示一个手柄的完整状态|被所有节点引用与发布|


|流向|内容|作用|
|---|---|---|
|STM32 → serial_data|原始数据帧（例如识别命令响应）|底层数据输入|
|serial_data → protocol_parser|HEX 转字节后解析命令|协议解释|
|protocol_parser → MassageHeadStatus.msg|生成 ROS 状态消息|抽象成统一格式|
|massage_head_manager → massage_head_status|发布状态|上层可订阅查看状态|
|massage_head_manager → massage_head_manager|下发命令（字符串）|串口节点负责写回 STM32|

```shell

# 示例
  GNU nano 6.2        /etc/udev/rules.d/99-massage-robot.rules                  
# 按摩机器人串口设备固化规则 - 严格基于物理USB端口路径
# 注意：移除了设备ID依赖，只基于物理端口KERNELS

# 物理端口 2-2.1:1.0 - 按摩头管理器 (无论插入什么设备)
SUBSYSTEM=="tty", KERNELS=="2-2.1:1.0", \
    SYMLINK+="tty_massage_head_manager", \
    GROUP="dialout", MODE="0666", \
    ENV{ID_ROBOT_DEVICE}="massage_head_manager", \
    ENV{ID_ROBOT_ROLE}="massage_head", \
    ENV{ID_ROBOT_PORT}="physical_port_1"

# 物理端口 2-2.2:1.0 - 系统管理器 (无论插入什么设备)
SUBSYSTEM=="tty", KERNELS=="2-2.2:1.0", \
    SYMLINK+="tty_system_manager", \
    GROUP="dialout", MODE="0666", \
    ENV{ID_ROBOT_DEVICE}="system_manager", \
    ENV{ID_ROBOT_ROLE}="system_control", \
    ENV{ID_ROBOT_PORT}="physical_port_2"


```
